# Mersad V1 — AI Alert Explanation

## 1. Purpose

This document defines the current state of AI-assisted alert explanation in Mersad V1 and distinguishes implemented functionality from future plans.

## 2. Current Implementation

AI-assisted alert explanation is not part of the currently verified V1 implementation.

The backend generates detections through registered, rule-based detection logic. Each detection includes information such as its rule ID, title, description, and severity. The alert service persists the resulting security findings, and the dashboard displays them.

These descriptions are generated by the detection logic. They should not be described as AI-generated explanations.

The code search across the backend and dashboard did not identify an AI client, model integration, or alert-explanation service.

## 3. Current Limitations

V1 does not currently provide a verified implementation of:

- Natural-language explanations generated by an AI model
- AI-generated investigation recommendations
- AI-assisted alert prioritization
- An AI provider integration or model configuration
- An explanation API endpoint

These capabilities must not be presented as existing product features.

## 4. Potential Future Design

AI-assisted explanations may be introduced in a future version to help an analyst understand an alert.

A future implementation could provide:
- A concise explanation of why an alert was generated
- Relevant evidence from the associated telemetry
- Suggested investigation steps
- Explicit uncertainty when available evidence is insufficient

This would be an additional explanation layer, not a replacement for the detection engine.

## 5. Security Considerations

Any future AI integration should:

- Send only the minimum telemetry required for the explanation
- Avoid exposing credentials, secrets, or unnecessary personal data
- Treat telemetry and process metadata as untrusted input
- Prevent model output from directly executing commands or changing security policy
- Keep detection results distinguishable from AI-generated recommendations
- Make provider configuration and data-handling behavior explicit

## 6. V1 Status

Rule-based detection, persistent alert storage, the alerts API, and dashboard presentation are implemented in the verified V1 flow.

AI-assisted alert explanation remains a future capability and requires a separate implementation and verification process.
